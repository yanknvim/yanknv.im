# こんにちは
yank.nvimです。そろそろyanknv.imの決定版を作ろうと思い、Astroでがんばってこねこねしました。

# 技術選定
現代においてSSGを使ってブログを作るとなると、やはりAstroの存在は無視できません。特に文句なく使えるため、採用しました。

スタイリングについては、これまた無難にTailwindにしました。CSS-in-JSも検討していたのですが、かなり導入コストが高そうなので試すなら真面目にWebサービスを作るときとかにします。

# デザイン
今回は珍しく、デザインに非常にこだわっています。一種のブルータリズムを取り入れ、シンプルで無骨なビジュアルにしました。モノトーンなので、ライトモードでもダークモードでも画になっていいですね。

フォントにもその理念は適用されており、LINE Seed JPとSpace Monoを組み合わせました。

特にデザインに詳しいわけでもないですが、自分なりに素敵に作ってみたのでぜひ何かを感じ取っていただけると。

# 実装
おおむね手でやりましたが、面倒なとこはLLMにやってもらいました。便利な時代です。

- 記事一覧の実装(スキーマは書いた)
- ダークモード

このへんを雑にやってもらえるのは嬉しい。半Vibeくらいのコーディングは気楽でいいですね。
